# Fetchly

Paste any video URL and instantly get download links. Supports MixDrop and direct video URLs.

## Features

- **Google-style UI** — Clean, minimal, familiar interface
- **MixDrop Support** — Paste any MixDrop URL and get direct download links
- **Watch Mode** — Preview videos directly in browser
- **Copy & Download** — One-click copy or download video files
- **HLS Support** — Detects and links m3u8 streams
- **Work Sans** — Clean typography across the whole site

## Supported Sites

- MixDrop (mixdrop.co, miiiixdrop.net, +30+ domains)
- Direct video URLs (.mp4, .webm, etc.)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy to Vercel

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/YOUR_USERNAME/fetchly)
